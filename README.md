# JavaScript Projects Collection

Welcome to my JavaScript projects repository!

This repo is a collection of vanilla JavaScript applications I built to practice and solidify my core web development skills. Instead of relying on frameworks like React or Vue, these projects are built entirely with HTML, CSS, and plain JavaScript to better understand the fundamentals of the DOM, APIs, and browser storage.

## 🚀 Projects Overview

Here is a quick breakdown of the four projects included in this repository:

### 1. Exchange Rate Calculator

A real-time currency converter that fetches live exchange rates from a public API.

- **Features:** Select two currencies, enter an amount, and instantly see the converted value. Includes a swap button to quickly reverse the currencies.
- **What I Practiced:** `fetch()` with `async/await`, handling API responses, JSON parsing, DOM manipulation, and event listeners.

### 2. Expense Tracker

A simple budgeting tool to track income and expenses.

- **Features:** Add new transactions with a name and amount, view your total balance, and delete individual transactions.
- **What I Practiced:** Array methods (`map`, `filter`, `reduce`), form handling, dynamically creating HTML elements, and using `localStorage` to persist data across page reloads.

### 3. Meal Finder

A recipe search app that pulls data from an external food API.

- **Features:** Search for meals by name (e.g., "chicken"), view a grid of results with images, and click on a meal to see full details and instructions.
- **What I Practiced:** API integration, handling URL parameters, CSS Grid for layout, and dynamic rendering of API data.

### 4. Menu Slider and Modal

A UI-focused project demonstrating interactive navigation and popups.

- **Features:** A side navigation menu that slides in and out smoothly, and a sign-up modal that overlays the page.
- **What I Practiced:** CSS transitions and transforms, toggling CSS classes with `classList`, and managing click events to open/close UI components.

## 🛠️ Technologies Used

- **HTML5** — Semantic markup and structure.
- **CSS3** — Styling, Flexbox, CSS Grid, and animations/transitions.
- **JavaScript (ES6+)** — DOM manipulation, Fetch API, Async/Await, and Local Storage.
